# Obraz demonstracyjny WMS

`wms-demo-wheel.png` jest obrazem wygenerowanym przez narzędzie imagegen
12 września 2026. Przedstawia fikcyjne koło kosiarki na białym tle.
Skrypt `server/src/wms-demo-run.ts` przypisuje je wyłącznie do demonstracyjnego
SKU `WMS-0030`. Nie przedstawia konkretnego modelu części ani towaru klienta.
Pozostałe SKU bez obrazu pokazują jawny brak zdjęcia; nie otrzymują wspólnego
zdjęcia zastępczego.
